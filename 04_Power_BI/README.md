## Tipos de analítica

**1. Descriptive Analytics — What happened?**  
Describe lo que ocurrió.

**2. Diagnostic Analytics — Why did it happen?**  
Busca las causas y patrones que explican los resultados.

Ejemplo: analizar cómo descuentos, productos, campañas y equipos de ventas influyen en el cierre de negocios.

**3. Predictive Analytics — What's likely to happen next?**  
Utiliza patrones históricos para estimar resultados futuros.

**4. Prescriptive Analytics — What should we do?**  
Evalúa diferentes alternativas para determinar qué acción podría generar mejores resultados.

**5. Cognitive Analytics — What can AI help us understand?**  
Utiliza IA para analizar grandes volúmenes de datos, especialmente información no estructurada, identificar patrones, sentimientos y relaciones difíciles de detectar manualmente.




Roles in Data Analytics

A modern data team distributes responsibilities across different roles:

Business Analyst → Data Engineer → Analytics Engineer → Data Analyst → Data Scientist

Business Analyst: defines business questions and KPIs.
Data Engineer: prepares and moves data.
Analytics Engineer: creates consistent data models.
Data Analyst: analyzes and visualizes data.
Data Scientist: develops predictive models.

Key concept:

Each role's output becomes the next role's input.

Learning: Data analytics requires collaboration between technical and business roles to transform data into actionable decisions.
