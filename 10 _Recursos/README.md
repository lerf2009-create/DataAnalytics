## 🎨 Visualización y accesibilidad

### Coblis — Color Blindness Simulator
Simulador para comprobar cómo pueden percibirse imágenes y
visualizaciones bajo diferentes tipos de deficiencia de visión
del color. Permite cargar una imagen y visualizarla mediante
diferentes simulaciones.

🔗 https://www.color-blindness.com/coblis-color-blindness-simulator/

### WebAIM — Contrast Checker
Herramienta para comprobar el contraste entre colores y evaluar
su accesibilidad visual.

🔗 https://webaim.org/resources/contrastchecker/
